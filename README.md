# 🏥 Diabetes Registry Analytics Dashboard

A professional Health Informatics dashboard built using **Python**, **Streamlit**, **Pandas**, **Plotly**, and **Machine Learning**.

---

## Features

- 📊 Interactive Dashboard
- 👥 Demographic Analysis
- 🩸 Laboratory Analysis
- ⚠️ Complication Analysis
- 🤖 Machine Learning Prediction
- 📈 Statistical Analysis
- 📄 Downloadable Reports

---

## Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn
- Jupyter Notebook
